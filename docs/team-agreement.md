## 2. 소통

- 채널: 카카오톡 채팅방 '음메'
- 정기 회의: 매주 월요일 18:30~19:30, 온라인. 불참 시 전날까지 알림
- 응답: 채팅 24시간, 풀 리퀘스트 리뷰 48시간

## 3. 작업 규칙

- 작업 전 이슈 등록, 하루 작업 끝에 Push
- 브랜치·커밋·풀 리퀘스트 규칙은 안내서 8장
- main.py·공통 파일을 고칠 때는 이슈 댓글로 먼저 알림

## 4. 의사결정

- 회의에서 다수결, 동률이면 개발 리드 결정. 결정과 이유는 회의록에 기록

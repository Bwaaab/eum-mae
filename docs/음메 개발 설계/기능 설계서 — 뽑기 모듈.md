# 기능 설계서 — 뽑기 모듈

- **작성자**: 장산
- **관련 Issue 번호**: `#`

---

## 1. 개요 및 목적

- 사용자가 선택한 음식 후보 중 하나를 무작위로 추첨한다. ‘메뉴 뽑기’ 버튼을 누르면 실행되며, 선정된 음식의 ID를 반환한다.

---

## 2. 입·출력 명세 (I/O)

### 📥 입력 데이터 (Input)

- 유저가 선택한 추첨 대상 음식의 ID 목록 `selected_ids: list[str]`

### 📤 출력 데이터 (Output)

- 추첨된 음식의 ID `selected_id: str`

---

## 3. 핵심 처리 로직 (Logic)

- 내부에서 순차적으로 일어나는 처리 흐름을 단계별로 정리합니다.
1. **유효성 검사**:
    - 전달받은 `selected_ids`가 문자열로 구성된 리스트인지 확인한다.
    - 리스트가 비어 있는 경우 추첨을 수행하지 않고 `ValueError`를 발생시킨다.
2. **핵심 연산 / 처리**:
    - Python 표준 라이브러리의 `random.choice()`를 사용하여 후보 중 하나를 무작위로 선택한다.
    - 후보 ID는 중복 없이 전달받는 것을 전제로 하며, 각 후보는 동일한 확률로 선택된다.
3. **결과 가공 및 반환**:
    - 선택된 음식 ID를 문자열(`str`)로 반환한다.
    - 호출한 `app.py`에서 해당 ID에 대응하는 음식 정보를 조회하고, 연출 및 결과 표시 모듈로 실행을 이어간다.

---

## 4. 예외 및 에러 처리 (Edge Cases)

- [ ]  **후보 목록이 비어 있는 경우:** 추첨을 수행하지 않고 `ValueError`를 발생시킨다. 화면에서는 후보가 선택되지 않았을 때 추첨 버튼을 비활성화하여 사전에 방지한다.
- [ ]  **입력 데이터 형식이 잘못된 경우:** 전달받은 데이터가 리스트가 아니거나, 리스트 내부에 문자열이 아닌 값이 포함되어 있으면 `TypeError`를 발생시킨다.
- [ ]  **등록되지 않은 음식 ID가 전달되는 경우:** 음식 저장소를 관리하는 `app.py`에서 ID의 유효성을 검증한다. 추첨 모듈은 저장소를 직접 참조하지 않고 전달받은 후보 내에서 선택만 수행한다.

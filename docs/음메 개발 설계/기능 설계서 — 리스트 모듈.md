## 1. 개요 및 목적

- 앱이 처음 목록을 그릴 때, 코드 안 시드로 기본 메뉴를 만들어 이름과 이미지를 보여 준다.
- 체크된 메뉴 ID를 돌려준다. 추가·삭제·세션 유지·추첨은 이 이슈 범위가 아니다.
- 관련 파일은 `menu_list.py`, `app.py`다. `models.py`는 수정하지 않고, 룰렛·결과창·이펙트 모듈은 import하지 않는다.
- `Food` 필드는 `id`, `name`, `image_path`만 쓴다. 한식/중식/일식/양식은 시드 안에서만 구분한다.

---

## 2. 입·출력 명세 (I/O)

### 📥 입력 데이터 (Input)

- `load_default_foods()`: 입력 없음. 외부 DB나 파일을 읽지 않는다.
- `render_menu(all_foods: list[Food])`: 화면에 그릴 `Food` 리스트. `list(registry.values())`처럼 사전 값에서 만든다.
- `Food` 필드

| 필드 | 타입 | 의미 | 예 |
| --- | --- | --- | --- |
| `id` | `str` | 음식 이름 영어 발음. dict의 키와 같다 | `"bibimbap"` |
| `name` | `str` | 화면에 보일 이름 | `"비빔밥"` |
| `image_path` | `str` | 이미지 파일 경로. 전용 사진이 없으면 `assets/images/default.png` | `"assets/images/bibimbap.png"` |

### 📤 출력 데이터 (Output)

- `load_default_foods() -> dict[str, Food]`: `id`를 키로 하는 메뉴 사전. `app.py`가 세션에 `registry`가 없을 때 이 값으로 초기화한다.
- `render_menu(...) -> list[str]`: 이름과 이미지를 그린 뒤, 체크된 메뉴 ID. 선택된 항목이 없으면 `[]`. 이 값이 추첨 입력이다.
- 최소 조건은 카테고리당 2개다. 시드에는 아래 표를 넣는다.

---

## 3. 핵심 처리 로직 (Logic)

- 내부에서 순차적으로 일어나는 처리 흐름을 단계별로 정리합니다.
1. **유효성 검사**:
    - 시드 `id`는 음식 이름 영어 발음이고, 목록 전체에서 겹치면 안 된다. 같으면 dict에서 앞 항목이 덮인다.
    - 같은 발음은 하나만 둔다. 예를 들어 우동은 일식 `udon`만 넣는다.
    - 사진 경로를 따로 적지 않은 항목은 `assets/images/default.png`를 쓴다.
2. **핵심 연산 / 처리**:
    - `load_default_foods` 안에 시드를 `(id, name)`으로 둔다. 구분은 주석이나 구역으로만 표시하고, `Food` 필드로는 넣지 않는다.
    - 목록을 돌며 `Food(id, name, "assets/images/default.png")`를 만든다. 전용 사진이 있는 항목만 경로를 바꾼다.
    - `id`를 키로 한 `dict`를 만든다. 키와 `Food.id`는 같다.

3. **결과 가공 및 반환**:
    - `load_default_foods`는 시드 dict를 반환한다. `app.py`는 `registry`가 없을 때만 이 값으로 세션을 초기화한다.

## 4. 예외 및 에러 처리 (Edge Cases)

- [ ]  **이미지 파일이 없는 경우:** 목록 출력은 계속한다. 해당 항목은 이름만 보여 주거나, 파일이 있는 `default.png`로 대체한다. 예외로 앱이 멈추면 안 된다.
- [ ]  **default.png도 없는 경우:** 이미지는 생략하고 이름 목록은 남긴다.
- [ ]  **메뉴 목록이 비어 있는 경우:** `all_foods`가 빈 리스트면 “메뉴가 없습니다”처럼 안내만 출력한다. 인덱스로 접근해 에러를 내지 않는다.
- [ ]  **시드 ID가 같은 경우:** 앞 항목이 덮이므로, 시드를 넣을 때 ID를 서로 다르게 둔다.
- [ ]  **외부 의존이 없는 경우:** `load_default_foods`는 인자, 파일 읽기, 다른 기능 모듈에 의존하지 않는다. 시드만으로 항상 같은 dict를 만든다.

## 1. 개요 및 목적

- **기능적 로직에 절대적으로 영향을 주지 않으며, 오로지 독립적으로 작동하는 이펙트 모듈을 설계**하는 것을 목적으로 한다.
    - 뽑기(가챠), 결과창, 메뉴 리스트 등 핵심 비즈니스 로직과 철저히 결합도(Coupling)를 분리하여, 이펙트 모듈 내부에서 에러가 발생하더라도 메인 서비스(메뉴 추천)가 중단되지 않도록 안전성을 보장한다.
    - 다른 팀원이 복잡한 애니메이션 메커니즘을 몰라도 단 한 줄의 함수 호출만으로 손쉽게 시각 연출을 제어할 수 있도록 한다.
- **원자 단위(Atomic)의 개별 이펙트**와 이들을 시나리오에 맞게 조합한 프리셋의 2계층 구조로 이펙트 시스템을 설계한다.
    - **높은 유연성과 편의성 제공**:
        - 세부적인 제어가 필요한 팀원은 개별 이펙트(컨페티, 번쩍임 등)를 직접 호출하여 사용 가능.
        - 빠른 구현을 원하는 팀원은 이펙트 담당자가 연출 타이밍을 맞춰둔 '완성형 세트(예: 잭팟 세트, 롤링 세트)'를 단 한 줄로 호출 가능.

## **2. 입·출력 명세 (I/O)**

### **📥 입력 데이터 (Input)**

| 파라미터명 | 타입 | 필수 여부 | 기본값 | 설명 |
| --- | --- | --- | --- | --- |
| `target` | `str` 또는 `Enum` | **필수** | - | 실행할 **단일 이펙트명** 또는 **세트 프리셋명** |
| `is_preset` | `bool` | 선택 | `False` | 입력된 타깃이 세트인지 단일 이펙트인지 명시 (자동 판별도 지원) |
| `duration` | `float` | 선택 | `None` | 세트 또는 개별 이펙트의 재생 시간 (미지정 시 프리셋 기본값 사용) |
| `options` | `dict` | 선택 | `{}` | 세부 옵션 (예: `{"intensity": "high", "color": "gold"}`) |

> **타깃 구분 예시**:
> 
> - **단일 이펙트(Atomic)**: `"confetti"`, `"flash"`, `"shake"`, `"cow_eating"`, `"cow_happy"`
> - **세트 이펙트(Preset)**: `"preset_gacha_spin"`, `"preset_jackpot"`, `"preset_normal_result"`

### **📤 출력 데이터 (Output)**

- **반환 타입**: `bool`

 렌더링 정상 실행 여부(`True` / `False`)만 반환하며 비즈니스 데이터에는 관여하지 않는다

## **3. 핵심 처리 로직 (Logic)**

1. **유효성 검사**:
    - 전달받은 `target`이 단일 이펙트 레지스트리 또는 프리셋 딕셔너리에 정의되어 있는지 조회한다.
    - 잘못된 이름인 경우 경고만 남기고 안전하게 `False`를 반환한다.
2. **핵심 연산 / 처리 (2-Track 분기 처리)**:
    - **Case A. 단일 이펙트 호출 시**:
        - 해당 이펙트의 전용 렌더러(Lottie 재생기, CSS 주입기, JS Canvas 파티클 등)를 직접 호출하여 단독 렌더링.
    - **Case B. 세트 이펙트(프리셋) 호출 시**:
        - 프리셋에 정의된 "이펙트 실행 파이프라인(목록 및 지연 시간)"을 순차/동시 순회.
        - 예: `preset_jackpot` 실행 시 → ① 화면 번쩍임(Flash) 0.3초 발생 → ② 젖소 환호 Lottie 출력 → ③ 0.2초 후 대형 컨페티(Confetti) 폭죽 발사.
3. **결과 가공 및 반환**:
    - 화면 렌더링을 완료하고 임시 플레이스홀더를 정리한 뒤 `True`를 반환한다.

---

## 4. 예외 및 에러 처리 (Edge Cases)

- **세트 실행 도중 특정 단일 이펙트(예: Lottie 에셋 누락) 실패 시**:
    - 에셋이 누락된 단일 효과만 건너뛰고(Skip), 세트에 포함된 나머지 효과(컨페티, CSS 등)는 중단 없이 끝까지 재생.
- **Streamlit 리런으로 인한 세트 이펙트 중복 재생 방지**:
    - `st.session_state`를 활용해 일회성 프리셋은 한 번만 트리거되도록 멱등성(Idempotency) 보장.

## 5. 함수 시그니처 초안 (Code Draft)

```python
from enum import Enum
from typing import Optional, Dict, Any, List

# 1. 단일 이펙트 종류 정의
class EffectType(str, Enum):
    CONFETTI = "confetti"        # 축포 파티클
    FLASH = "flash"              # 화면/카드 번쩍임
    SHAKE = "shake"              # 화면 흔들림
    COW_IDLE = "cow_idle"        # 젖소 대기 모션
    COW_EAT = "cow_eat"          # 젖소 입 벌림/흡입
    COW_HAPPY = "cow_happy"      # 젖소 환호

# 2. 세트(프리셋) 조합 템플릿
EFFECT_PRESETS: Dict[str, List[Dict[str, Any]]] = {
    # 잭팟/대박 결과 세트: 번쩍임 + 젖소 환호 + 대형 축포
    "preset_jackpot": [
        {"type": EffectType.FLASH, "options": {"color": "gold", "duration": 0.5}},
        {"type": EffectType.COW_HAPPY, "options": {"duration": 2.0}},
        {"type": EffectType.CONFETTI, "options": {"intensity": "high"}},
    ],
    # 룰렛 회전 세트: 젖소 입 열림 + 가벼운 진동
    "preset_rolling": [
        {"type": EffectType.COW_EAT, "options": {"duration": 2.5}},
        {"type": EffectType.SHAKE, "options": {"intensity": "low"}},
    ],
    # 일반 결과 세트: 기본 축포
    "preset_normal_result": [
        {"type": EffectType.CONFETTI, "options": {"intensity": "medium"}},
    ]
}

def play_atomic_effect(effect: EffectType, options: Optional[dict] = None) -> bool:
    """[단일 이펙트] 개별 효과를 화면에 독립적으로 출력합니다."""
    try:
        if effect == EffectType.CONFETTI:
            # 컨페티 JS 파티클 렌더링
            ...
        elif effect == EffectType.FLASH:
            # CSS 플래시 애니메이션 주입
            ...
        elif effect == EffectType.COW_EAT:
            # 젖소 Lottie 애니메이션 재생
            ...
        return True
    except Exception:
        return False

def play_preset(preset_name: str, options: Optional[dict] = None) -> bool:
    """[세트 이펙트] 여러 개별 효과가 조합된 사전 정의 연출 세트를 순차 실행합니다."""
    if preset_name not in EFFECT_PRESETS:
        return False
    
    sequence = EFFECT_PRESETS[preset_name]
    for step in sequence:
        # 세트 안의 단일 효과들을 순차적으로 실행
        play_atomic_effect(step["type"], step.get("options"))
    return True

def play_effect(target: str, is_preset: bool = False, options: Optional[dict] = None) -> bool:
    """
    [통합 인터페이스] 팀원이 단일 효과든 세트 효과든 편리하게 호출할 수 있는 통합 진입점.
    target 이름이 'preset_'으로 시작하거나 is_preset=True이면 세트 효과로 자동 분기합니다.
    """
    if is_preset or target.startswith("preset_"):
        return play_preset(target, options)
    return play_atomic_effect(EffectType(target), options)
```

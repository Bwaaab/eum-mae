## 3. 논의 내용과 결정 사항 (이유 포함)

1. 브랜치 명명 규칙에서 # 기호 제외 (feature/이슈번호-기능명)
    - 이유: Git 명령어 환경에서 # 문자가 파싱 오류나 주석 처리를 유발할 수 있어, 안전한 브랜치명 유지를 위해 숫자로만 표기하기로 결정함.
2. 주간 1인 1이슈 등록 원칙 준수 및 세부 작업 분할
    - 이유: 개인별 활동 평가 점수를 충족하기 위해 매주 팀원 전원 최소 1건 이상의 이슈를 등록하고, 금주 중 담당 기능에 대한 세부 작업 이슈 3건씩을 추가 등록하기로 함.
3. 공통 모듈 아키텍처 기반 개발 착수
    - 이유: 개발 리드가 중앙 집중식 모듈 구조로 작성한 노션 설계 문서를 사전에 숙지하여 파일명과 함수 규격을 일치시킴으로써 향후 병합 충돌을 방지하기 위함.

## 3. 논의 내용과 결정 사항 (이유 포함)

1. **메인 화면 및 메뉴 선택·추가 UI 전면 개편 확정**
    - **내용:**
        - **메뉴 그리드 UI 및 카테고리 전환:** 메뉴 후보를 가로·세로 행렬(그리드) 형태의 큰 버튼 블록(사진 + 메뉴명 + 선택 색상 변화)으로 배치해 모바일 터치 편의성을 높이고, 전체 메뉴 보기와 카테고리별 필터 버튼(`전체` / `한식` / `중식` / `일식` / `양식` 등)을 모두 제공함.
        - **입력창과 선택창 분리:** 메뉴 선택 목록 상단에 고정되어 있던 메뉴 이름·사진 업로드 입력 폼을 분리하여, 별도 `메뉴 추가` 버튼 클릭 시 팝업창(모달)으로 열리도록 수정함.
        - **메인 화면 문구 및 버튼 배치 정리:** 메인 화면 상단의 중복 문구(`오늘 뭐 먹지?`)를 삭제하고, `오늘의 메뉴 뽑기!` 버튼을 중앙 하단에 큼직하게 배치함.
    - **이유:** 120여 개 메뉴가 늘어날수록 기존 체크박스 리스트의 가독성과 모바일 터치 조작성이 떨어지며, 입력 폼과 선택 영역을 분리해야 화면 구성이 직관적이고 깔끔해지기 때문.
2. **결과 화면 UI 개편 및 젖소 연출·버튼 연동 확정**
    - **내용:**
        - 기존 결과 카드 하단에 출력되던 공유용 텍스트 코드블록 및 중복 다운로드 영역을 삭제함.
        - 추첨 시 젖소 캐릭터가 입을 벌린 상태가 결과 출력 시까지 유지되도록 연동하고, 젖소가 뱉어낸 카드 영역을 확대해 최종 당첨 메뉴 카드(오늘의 추천 메뉴, 음식 이미지, 메뉴명)가 크게 표시되도록 구성함.
        - 결과 카드 출력 시 축하 파티클(컨페티) 이펙트가 함께 실행되도록 연동하고, 카드 바로 아래에 `저장하기` 및 `다시뽑기` 버튼을 배치함.
        - 전체 배경의 단조로움을 개선하기 위해 배경 이미지를 추가 적용함.
    - **이유:** 프로젝트 핵심 정체성인 젖소 연출과 당첨 결과 화면을 자연스럽게 연결하고, 불필요한 중복 UI를 제거해 사용자 경험을 일관되게 다듬기 위함.
3. **작업 브랜치 순차 분기 원칙 재확인 및 타 팀 기여 PR 검수**
    - **내용:** 동일 파일이나 의존 관계가 있는 후속 이슈(`#77` → `#87`, `#23` → 후속 UI 개편) 작업 시에는 반드시 선행 브랜치가 `main`에 병합된 뒤 최신 `main` 기준으로 새 브랜치를 분기하여 진행함. 또한 외부 팀 기여 마감(11/26) 전까지 우리 저장소로 들어오는 타 팀 PR을 신속히 리뷰·승인함.
    - **이유:** 미병합 브랜치 위에서 하위 브랜치를 파생할 경우 불필요한 병합 충돌과 이력 꼬임이 발생하기 때문.

## 3. 논의 내용과 결정 사항 (이유 포함)

1. **타 팀(8팀) `README.en.md` 영문 번역 분량 분배 및 순차 브랜치·PR 진행 확정**
    - **내용:** 8팀 저장소(`Bwaaab/foss-8`)의 영문 리드미(`README.en.md`) 작성 작업을 팀원 4명이 모두 커밋 이력을 남길 수 있도록 구간과 일정을 분배함.
        - **1~82줄 번역 및 1차 커밋·PR:** 장산 (마감: 11/17)
        - **83~122줄 번역 및 2차 커밋·PR:** 이규민 (마감: 11/18)
        - **123~166줄 번역 및 3차 커밋·PR:** 김가연 (마감: 11/19)
        - **한·영 README 전환 링크 추가, 실행 검증 및 원본 저장소(upstream) 최종 PR 제출:** 석혜인
        - **작업 방식:** 1브랜치 1작업자 규칙에 따라 각자 브랜치를 생성하여 Fork 저장소(`Bwaaab/foss-8`)에 PR 및 병합한 뒤, 앞선 작업자의 PR이 병합된 최신 `main` 기준으로 다음 담당자가 브랜치를 분기하여 충돌 없이 순차 진행함.
    - **이유:** 평가 기준상 팀원 전원에게 기여한 저장소 및 커밋 기록이 남아야 하며, 동일 파일을 수정하는 만큼 선행 병합 후 분기해야 병합 충돌을 방지할 수 있기 때문.
2.  **`menus.csv` 디렉토리 경로 수정(`docs/` → `data/`) 및 코드 반영 결정**
    - **내용:** 현재 `docs/` 디렉토리 하위에 잘못 배치된 `menus.csv` 파일을 `data/` 디렉토리로 이동하고, `modules/menu_list.py`의 파일 로드 경로를 일괄 수정한 뒤 PR을 통해 빠르게 `main`에 병합하기로 함.
    - **이유:** 우리 저장소 이슈(`#52`)에 참여하는 외부 기여자가 CSV 파일 위치 차이로 인해 혼선을 겪고 있어, 즉시 경로를 바로잡아 안내하기 위함.
3. **자체 프로젝트 UI 개선 및 기본 이미지 누락 보완**
    - **내용:** 메뉴 항목 증가 시 가독성 저하를 방지하기 위해 메뉴 리스트 UI를 개선하고, 사용자가 이미지 없이 새 메뉴를 추가할 경우 기본 이미지(`default`)가 자동 지정되도록 예외 처리를 보완하기로 함. 또한 PR `#72`의 병합 충돌을 해결하고 주간 개인 필수 활동(이슈 1개, 커밋 2회 이상)을 지속함.
    - **이유:** 사용자 편의성과 데이터 무결성을 높이고, 12주차 개인별 GitHub 활동 평가 기준을 누락 없이 충족하기 위함.
